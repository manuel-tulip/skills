
  # episodes - Slice sessions into episodes at real user instructions; tool
  mix
  + idle gaps

  For more help, run: go-minitrace help episodes

  Run go-minitrace help --ui to open the interactive help TUI.

  ## Usage:

  go-minitrace query commands docmetrics episodes [flags]

  ## Arguments:

             -h, --help    help for episodes
            --long-help    Show long help

  ## Query execution settings:

         --archive-glob    Repeatable glob flag for minitrace session JSON
  files to load - <stringList> (default [./output/active/*/*.minitrace.json])
              --db-path    Deprecated: ignored by SQL commands, still exposed
  to JS commands via mt.runtime - <string> (default ":memory:")
       --persist-loaded    Deprecated: ignored by SQL commands, still exposed
  to JS commands via mt.runtime - <bool>
           --table-name    Deprecated: ignored by SQL commands, still exposed
  to JS commands via mt.runtime - <string> (default "sessions_base")

  Use go-minitrace query commands docmetrics episodes --help --long-help for
  information about all flags.
